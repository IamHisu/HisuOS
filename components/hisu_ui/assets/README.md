# UI Assets

## Boot Splash

`boot_windows_xp_source.gif` preserves the original user-supplied 498 x 374 GIF.
`boot_windows_xp.gif` is generated by `tools/prepare-boot-gif.cjs` using Sharp:
240 x 240 with proportional fit and a black letterbox, preserving all 18 frames
and their original delays. LVGL's AnimatedGIF decoder has a 480 px width limit,
so it cannot load the 498 px original even when the image widget scales it down.
Only the compatible 240 x 240 asset is embedded; runtime scaling is not needed.
Use Node with Sharp available (the bundled runtime supplies it) to regenerate.
The splash plays for 3000 ms before entering the normal Hisu UI.

The duration is controlled by `HISU_BOOT_SPLASH_MS` in `src/hisu_ui.c`.
The splash runs in the regular UI task with scheduler yields, not a blocking
system-wide startup delay. There are no status icons, clock, header or footer
during startup. If decoding fails, the splash stays black for its duration,
rather than showing idle icons early. Deleting the
splash objects on transition releases their animation resources.

Windows XP artwork and Microsoft branding belong to their respective owners;
this user-supplied asset is not covered by HisuOS's source code license.
Review redistribution rights before publishing firmware containing it.

There are no bundled idle wallpapers. The idle screen uses the uploaded media
or a solid black/white theme background on missing/invalid media. This boot-only
animation does not replace saved wallpaper, settings, navigation or subtitles.
